IMPORTANT:
BOT OWNER and SERVER ADMIN are NOT the same thing.

BOT OWNER:
- Has access to owner-only commands.
- Can modify the bot's server profile/branding.
- Can use .cmds.
- Can access owner-level configuration.

SERVER ADMIN:
- Has Discord Administrator permission.
- Can use .cmds.
- Can use normal server administration features.
- Does NOT automatically become a bot owner.
- Does NOT automatically receive bot-profile/branding permissions.
- Does NOT automatically receive blacklist permission.
